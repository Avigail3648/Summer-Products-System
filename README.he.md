# **פרוייקט אתר להזמנת מוצרי קיץ**

## עברית

### טכנולוגיות בשימוש
- **צד לקוח (Frontend)**: פותח באמצעות React.
- **צד שרת (Backend)**: פותח באמצעות Node.js ו־Express.
- **מסד נתונים**: MongoDB.


### הוראות התקנה מקומית
כדי להפעיל את הפרויקט במחשב מקומי, יש לבצע את השלבים הבאים:

1. שיבטו את הרפוזיטורי:  
   `git clone https://github.com/AvigailCohen3468/Summer-Products-Website-Project.git`
2. עברו לתיקיית הפרויקט:  
   `cd Summer-Products-Website-Project`
3. התקינו את התלויות:  
   `npm install`
4. הפעילו את שרת הפיתוח:  
   `npm start`
5. פתחו את הדפדפן ועברי לכתובת `http://localhost:3000` לצפייה בפרויקט.


### איך לתרום לפרויקט
1. בצעו Fork לרפוזיטורי.  
2. צרו ענף חדש (`git checkout -b feature-branch`).  
3. בצעו שינויים ו־commit (`git commit -am 'Add feature'`).  
4. דחפו את השינויים לענף החדש (`git push origin feature-branch`).  
5. פתחו Pull Request לענף הראשי.
